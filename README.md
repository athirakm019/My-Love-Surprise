# A Magical Love Surprise Website for My Boyfriend 💗👑

A romantic, dreamy, and interactive pink princess-themed digital love gift created especially for my favourite human.

---

## 🌸 Theme & Features

- **Pink Romantic Princess Aesthetic**: Dreamy baby pinks, rose gold, soft lavender, cursive typography, floating hearts, and falling rose petals.
- **First Opening Screen**: Full-screen surprise greeting with an interactive 3D pink envelope and a glowing **"OPEN YOUR SURPRISE 💌"** button.
- **Big "I LOVE YOU" Surprise**: Huge glowing cursive typography (`"I LOVE YOU SO MUCH ❤️"`), interactive floating emojis (`❤️ 💗 💕 💖 💘 💝 🥰 😘 💋 🌹 🦋`), and falling petals.
- **His Personal Photo Gallery**: Masonry Pinterest-style gallery dedicated entirely to boyfriend photos with Polaroid-style cards, romantic borders, captions, and full-screen Lightbox navigation (30+ photos capacity).
- **Special Memory Wall**: Romantic scrapbook section with paper textures, dates, polaroid pictures, heart stickers (`🎀 🌸 💖 💌 ✨ 🧸`), and handwritten memories.
- **Animated Love Letter**: Pink envelope with heart wax seal that opens to reveal the parchment handwritten note.
- **Unlimited Love Button**: Giant glowing pink heart button that tracks kisses and explodes into floating hearts, kisses (`💋`), and butterflies.
- **Romantic Background Music Player**: Floating player with play/pause, volume slider, mute toggle, and gentle piano melody.
- **Final Grand Surprise**: His favourite picture inside an illuminated glowing heart frame, 3 cascading grand quotes, and pink fireworks.
- **Secret Surprise Easter Egg**: Subtle floating heart in the bottom corner that unlocks a secret love message after 3 taps.
- **Password-Protected Admin Customization Studio**: Private dashboard (password: `love123`) to upload boyfriend photos, change captions, edit the love letter, manage scrapbook memories, and export a complete portable JSON backup.

## 🚀 Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.

---

## 👑 Customization & Admin Mode

1. Scroll to the footer and click the discreet **"Customize Surprise"** lock icon, or visit with `?admin=true` in the URL.
2. Enter the admin password: `love123` (you can change this password in the studio).
3. **Upload Real Photos**: In the Photos tab, select all boyfriend photos (supports JPG, PNG, WEBP).
4. **Choose Favourite Photo**: Click "Set as Finale" on his best photo to display it in the glowing heart frame at the end of the website.
5. **Edit Letter & Memories**: Tailor every message to your personal love story.
6. **Backup**: Click **"Download Gift Package (.json)"** to save your photos and personalized configuration safely.

## 🌐 Deploying to Vercel

1. Push this project to GitHub.
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Framework Preset: **Vite**.
5. Click **Deploy**!
6. Share the public Vercel URL with your boyfriend! 💗
